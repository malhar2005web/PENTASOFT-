# REQUIREMENTS.md — Project Specifications

## Functional Requirements
1. **Single-Scroll Architecture**: Continuous visual experience with clean section transitions.
2. **Interactive 3D Levitating & Rotating Laptop**:
   - Continuous levitation float animation when idle.
   - Interactive mouse hover tracking: when cursor hovers over the 3D hero container, laptop rotates towards mouse position smoothly.
   - PBR metallic chassis, illuminated keyboard, glowing code screen.
3. **Responsive Layout**: Mobile-first responsive design adapted for 4K, Desktop, Laptop, Tablet, and Mobile.
4. **Anchor System Navigation**: Transparent floating glass header with active section tracking.
5. **No Fake Claims Rule**: Maintain integrity. No fake awards, fake client names, or exaggerated numbers. Use clear concept showcases.

## Non-Functional Requirements
- **Performance**: 60fps WebGL rendering, GPU acceleration, optimized CSS glass blur.
- **Accessibility**: Semantic HTML5 tags, `prefers-reduced-motion` compliance, visible keyboard focus indicators.
- **SEO Baseline**: OpenGraph cards, proper title hierarchy (`h1` per page), fast first paint.
